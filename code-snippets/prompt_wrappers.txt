# Prompt Wrappers — Copy/Paste Ready
# Use these to wrap your prompts when chatting with Copilot, Claude, or ChatGPT.
# Pick the wrapper that matches your desired output length.

# ── SHORT (≤ 3 sentences, inline answers, commit messages) ──────────────

[SHORT]
Answer in ≤ 3 sentences. Be precise and omit pleasantries.
Return only the requested content — no markdown fences, no commentary.
If a character limit is specified, enforce it strictly.
[/SHORT]


# ── DETAILED (PR bodies, architecture docs, 400–600 words) ─────────────

[DETAILED]
Provide a thorough, well-structured answer.
Use Markdown headings (##), bullet lists, and code blocks where helpful.
Target 400–600 words. Include a one-line summary at the top.
Do not exceed 800 words.
[/DETAILED]


# ── COMPACT (CI automation, JSON responses) ─────────────────────────────

[COMPACT]
Return a single JSON object with exactly these keys:
  "summary"  — string, ≤ 120 characters
  "details"  — string, ≤ 500 characters
No other text outside the JSON. No markdown fences.
[/COMPACT]


# ── COMMIT MESSAGE ──────────────────────────────────────────────────────

[COMMIT]
Write a conventional-commit message for the diff below.
Subject line: imperative mood, ≤ 72 characters.
Optional body: wrapped at 72 characters, separated by blank line.
Prefix: one of feat|fix|docs|chore|test|refactor|style|ci.
Return ONLY the commit message.
[/COMMIT]


# ── PR BODY ─────────────────────────────────────────────────────────────

[PR-BODY]
Write a GitHub PR description. Include:
1. One-line summary (≤ 120 chars)
2. ## Changes — bullet list (≤ 10 items)
3. ## How to verify — numbered steps (≤ 5)
4. ## Test status — one line
Total ≤ 800 words. Markdown format. No extra commentary.
[/PR-BODY]


# ── FILE ONLY (no explanation, just code) ───────────────────────────────

[FILE-ONLY]
Return only the file contents. No explanation before or after.
No markdown fences unless the file is markdown. Respect the original
indentation style of the project (4 spaces for Python).
[/FILE-ONLY]


# ── EXCERPT (first N lines) ────────────────────────────────────────────

[EXCERPT N=10]
Return only the first 10 lines of the output.
If there is more content, append "..." on a new line.
[/EXCERPT]
